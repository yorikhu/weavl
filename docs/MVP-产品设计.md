# Weavl 织光 · MVP 产品设计文档

> 依据：《Weavl 织光项目立项书》（飞书 wiki，rev 144）
> 版本：v0.1（2026-09-03） · 状态：草案
> 配套文档：docs/产品架构图.md（含架构图、用户旅程、对象模型）

---

## 0. 一句话产品定义

> **Weavl = 预设驱动的内容运营工作台**：运营者选一个预设、填一张业务表单、导入商品素材，系统跑完"选题→文案→配图→视频→检查"全流程，在关键节点由人确认，最终交付一个可直接发布到小红书的内容包。

**MVP 只验证一件事**：商品素材 → 小红书种草图文/短视频 → 人工确认 → 发布内容包。

## 1. 设计原则（从立项书推导，全程约束设计决策）

| #   | 原则                           | 含义                                              | 反例（禁止出现）       |
| --- | ------------------------------ | ------------------------------------------------- | ---------------------- |
| P1  | 预设即产品                     | 用户的所有入口都是"业务目标"，不是模型/节点/Agent | 首页放"选择大模型"入口 |
| P2  | 表单+对话，不暴露工作流        | 用户填写业务语言（商品/人群/调性），流程在后台    | 给用户看节点连线画布   |
| P3  | 人工确认点是产品特性，不是缺陷 | 选题/脚本/关键画面/成片四个节点强制可介入         | 追求"一键全自动出片"   |
| P4  | 交付物是内容包，不是素材文件   | 输出按渠道规格组织（标题/正文/封面/配图/话题）    | 只给一堆散图和 txt     |
| P5  | 资产必须回流                   | 每次任务的过程与产物沉淀为资产，可被下次调用      | 任务完成即丢弃中间产物 |
| P6  | 70-80% 自动化承诺              | 系统稳定完成标准生产，人聚焦策略/审美/审核        | 宣传"完全替代运营"     |

## 2. MVP 范围边界

### 2.1 做（In Scope）

- **一个核心预设**：商品小红书种草内容包（图文版 + 短视频脚本版）
- **四类用户对象**：工作空间（个人/团队）、品牌库、素材库、内容任务
- **人工确认**：选题、文案、配图/关键画面、成片四节点
- **质量检查**：违禁词、敏感表达、小红书规格（字数/图片比例/话题格式）、品牌一致性（调性关键词）
- **交付**：内容包导出（ZIP：文案 txt + 图片 + 封面 + 话题 + 发布建议）；应用内小红书样式预览
- **数据回流（轻量）**：内容包内附"回填表现数据"表单（曝光/点赞/收藏/评论），手动回填

### 2.2 不做（Out of Scope，写死防蔓延）

- ❌ 抖音/视频号等其他渠道（预留输出规范接口）
- ❌ 视频成片合成（MVP 只到脚本+分镜+关键画面；成片是 V1.1）
- ❌ 授权直发小红书（MVP 只导出；合规条件成熟后接）
- ❌ 预设市场/第三方预设（MVP 只有官方预设）
- ❌ 自由画布/节点编排器（高级配置层 V1.2 再开）
- ❌ 团队协作/审批流（MVP 单人使用；团队空间 V1.1）
- ❌ 自动数据抓取（表现数据先手动回填）

## 3. 核心对象模型

```
Workspace 工作空间
 ├─ BrandKit 品牌库（0..n）
 │    调性关键词、禁用词、视觉规范、参考图、账号信息
 ├─ Asset 素材（0..n）
 │    类型：商品图/素材视频/文档/生成物；来源：上传/生成/任务沉淀
 ├─ Preset 预设（引用官方库，可实例化为 Personal Preset）
 │    定义：表单 Schema + 工作流编排 + 确认点配置 + 输出规范
 └─ ContentTask 内容任务（0..n）
      输入快照（表单值 + 引用素材）
      ├─ Run 执行记录（0..n，每次运行一版）
      │    ├─ Step 步骤（选题/文案/配图/视频脚本/检查）
      │    ├─ Artifact 中间产物（多版本候选，支持抽卡）
      │    └─ Confirmation 确认记录（谁/何时/采纳哪版/备注）
      ├─ ContentPackage 内容包（终态产物，版本化）
      │    标题、正文、封面、配图组、视频脚本、话题、发布建议
      │    └─ PerformanceData 表现数据（手动回填）
      └─ 状态机：draft → running → awaiting_confirmation
                 → confirmed → packaged → delivered/archived
```

**关键设计决定**：

1. **输入快照**：任务创建时对表单值和引用素材做快照，避免素材被删改后任务不可复现。
2. **Run 每次全量记录**：用户"重新生成"开新 Run 而非覆盖，保留抽卡历史，也是质量判断数据的来源。
3. **Artifact 多候选**：文案/配图每步默认产出 3 个候选（可配 1-5），确认操作=采纳其一或要求重生成。
4. **ContentPackage 版本化**：用户导出后仍可修改再导出，旧版本保留，"采纳率/发布率"按版本追踪。

## 4. 产品架构（MVP 视角）

```
┌─────────────────────────────────────────────────────────┐
│  入口层  预设广场(1个核心预设) │ 我的任务 │ 素材库 │ 品牌库   │
├─────────────────────────────────────────────────────────┤
│  任务层  任务创建向导 │ 任务工作台(确认点) │ 内容包预览/导出  │
├─────────────────────────────────────────────────────────┤
│  预设层  表单Schema │ 步骤编排 │ 确认点 │ 输出规范 │ 检查规则 │
├─────────────────────────────────────────────────────────┤
│  引擎层  LLM文案 │ 文生图 │ 图文理解 │ 违禁词/规格检查      │  ← 模型可替换
├─────────────────────────────────────────────────────────┤
│  资产层  素材库 │ 品牌库 │ 任务历史 │ 产物沉淀 │ 表现数据    │
└─────────────────────────────────────────────────────────┘
```

**模型抽象**：引擎层所有能力声明为 `Capability`（如 `copywriting.xhs`、`image.product-photo`、`video.script`），预设引用 Capability 而非具体模型。好处：① 模型商品化风险对冲（P 风险表第 1 条）；② 后续按 Capability 计量计费。

## 5. 核心用户旅程（MVP：商家运营者"小林"）

**场景**：小林经营一家香薰蜡烛淘宝店，想在店铺小红书账号发种草笔记。

| 步骤                          | 用户动作                                                              | 系统行为                                                                        | 设计要点                                                   |
| ----------------------------- | --------------------------------------------------------------------- | ------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| 1. 选预设                     | 首页点「商品小红书种草内容包」                                        | 展示预设说明：需要什么素材、产出什么、约几分钟                                  | 说人话："你给我们商品资料，我们给你能直接发的笔记"         |
| 2. 填表单                     | 填商品名/链接、卖点、价格带、目标人群、调性（可选关联品牌库自动带出） | 表单校验；提示缺什么                                                            | 表单字段=业务语言；≤8 个字段，5 分钟内可完成               |
| 3. 备素材                     | 上传商品图（3-10 张）、可选素材视频/详情页文档                        | 图片打标分类（白底图/场景图/细节图）；入素材库                                  | 支持从素材库选择已有素材；生成物自动回流素材库             |
| 4. **确认①选题**              | 从 3 个选题角度中选 1（或调整后确认）                                 | 基于商品+人群+热点生成 3 个选题角度，每个含标题方向+切入角度+预期互动点         | 第一个确认点：方向错了后面全废，所以放最前                 |
| 5. 生成文案                   | 等待 ~30s；浏览 3 版文案                                              | 按小红书笔记结构生成：标题(≤20字)+正文(300-800字)+话题标签                      | 每版标注差异点（如"测评型/故事型/清单型"）                 |
| 6. **确认②文案**              | 选 1 版，可在线编辑微调，确认                                         | 保存编辑差异（用于学习用户偏好）                                                | 行内编辑器；"重生成"可附一句修改意见                       |
| 7. 生成配图                   | 等待；浏览封面 3 版 + 配图方案                                        | 封面：商品图+标题文字排版 3 版；配图：从上传图筛选/裁剪 + 可选 AI 补图          | AI 补图仅当上传图不足时触发，标注"AI 生成"                 |
| 8. **确认③关键画面**          | 逐张确认/替换/重生成                                                  | 图片规格检查（3:4、清晰度）；违禁元素提示                                       | 可回退用原商品图，保底不翻车                               |
| 9. 视频脚本（可选模块）       | 确认脚本+分镜+口播要点                                                | 生成 30-60s 口播脚本、分镜表（画面提示+字幕+时长）                              | MVP 不合成成片；导出分镜 PDF 供剪辑                        |
| 10. 质量检查                  | 查看检查报告                                                          | 违禁词/敏感表达/广告法用语/品牌调性一致性/平台规格，5 项全过才可打包            | 红黄绿三级；黄=警告可手动忽略并留痕                        |
| 11. 打包预览                  | 手机框内预览小红书发布效果                                            | 按小红书信息流样式渲染内容包                                                    | 所见即所得；分享只读链接给同事（MVP 不做账号体系，用链接） |
| 12. 导出/交付                 | 下载 ZIP / 复制文案                                                   | ZIP：文案.txt、封面.jpg、配图/、脚本.pdf、发布建议.md（含发布时间建议）、README | 内容包编号可追踪；导出即记一次"可交付"（北极星分子）       |
| 13. 回填数据（发布 3-7 天后） | 在任务页填曝光/点赞/收藏/转化                                         | 更新任务表现记录；沉淀"该选题角度表现"                                          | 手动回填是 MVP 妥协；V1.1 做提醒，远期自动抓取             |

**全程耗时目标**：新用户首任务 ≤ 30 分钟；熟练用户 ≤ 10 分钟。

## 6. 功能模块与优先级

### P0（MVP 必须，缺了闭环不成立）

| 模块          | 功能点                                                                     |
| ------------- | -------------------------------------------------------------------------- |
| M1 预设广场   | 官方预设卡片（MVP 仅 1 个）、预设详情页（输入说明/输出示例/耗时预估）      |
| M2 任务向导   | 表单（动态 Schema 渲染）、素材上传与选择、品牌库关联                       |
| M3 任务工作台 | 步骤流 UI、四确认点、多候选抽卡、行内编辑、重生成（带反馈意见）、版本历史  |
| M4 内容包     | 小红书预览、质量检查报告、ZIP 导出、发布建议、只读分享链接                 |
| M5 素材库     | 上传/预览/打标/搜索；生成物自动回流；任务引用快照                          |
| M6 品牌库     | 调性关键词、禁用词表、参考图、账号信息；表单自动带入                       |
| M7 引擎集成   | LLM（文案/选题）、文生图（封面/补图）、图片理解（打标）；Capability 抽象层 |
| M8 检查引擎   | 违禁词库（内置 + 品牌库自定义）、广告法用语、小红书规格、调性一致性        |
| M9 基础账户   | 注册/登录、个人空间、用量记录（为计费预留）                                |
| M10 埋点      | 北极星及配套指标全量埋点（见 §8）                                          |

### P1（MVP 后第一个迭代，验证留存）

- 视频成片合成（口播 TTS + 素材混剪）；抖音输出规范；团队空间与分享协作；预设参数"高级配置层"（提示词可见可微调）；表现数据提醒与简单分析（哪种选题角度效果好）

### P2（生态方向，立项书第八章增长路径对应）

- 官方预设扩展到 3-5 个；预设复制/版本化；服务商工作空间；数据回流自动化；认证预设市场

## 7. 关键界面清单（页面级描述，供 UI 设计输入）

1. **首页/预设广场**：顶部一句话价值主张 + 核心预设大卡 + "我的任务"入口。设计目标：3 秒看懂"这是帮我出小红书内容的"。
2. **预设详情页**：输入清单（要准备什么）、输出示例（真实内容包截图）、步骤图（含确认点标注）、预计耗时。
3. **任务创建向导**：左表单右素材栏；进度指示（1 填写 → 2 素材 → 3 开始）。
4. **任务工作台**：纵向步骤流，当前步骤展开、历史折叠收起；每步骤卡内为候选卡片（大图/全文）+ 确认按钮；顶部任务状态与"距上次保存"。
5. **确认点组件（全局统一）**：候选对比视图 + 采纳/编辑后采纳/重生成（附意见）三操作 + 确认人时间留痕。
6. **检查报告页**：五项检查行 + 展开 问题定位到具体文字/图片 + "忽略并说明理由"入口。
7. **内容包预览**：iPhone 框内模拟小红书信息流卡片、详情页；底部操作：导出/分享/新建版本。
8. **素材库**：网格式 + 筛选（类型/来源任务/标签）；上传弹层支持拖拽多文件。
9. **品牌库**：表单式编辑；调性关键词标签化输入。
10. **任务列表**：状态筛选（草稿/待确认/已交付）；排序（最近/状态）。

## 8. 指标体系（埋点清单）

**北极星**：每周完成并进入"可发布/可交付"状态的内容任务数（定义：任务产生至少一个导出或分享的内容包）

| 层   | 指标                          | 埋点事件（示例）                                |
| ---- | ----------------------------- | ----------------------------------------------- |
| 获取 | 新用户激活（完成首个任务）    | `task_created` `package_exported`(first)        |
| 效率 | 素材导入→可交付时长           | `task_started` ↔ `package_exported` 时间差      |
| 效率 | 每任务人工修改轮数            | `artifact_rejected` `regenerate_requested` 计数 |
| 质量 | 检查通过率/警告忽略率         | `check_passed` `check_warning_ignored`          |
| 采纳 | 内容包采纳率（导出/生成总数） | `package_created` vs `package_exported`         |
| 复用 | 7/30 日预设复用率             | 同 user+preset 重复 `task_created`              |
| 回流 | 表现数据回填率                | `performance_submitted`                         |
| 商业 | 单任务模型成本                | 引擎调用日志按任务聚合                          |
| 协作 | 分享链接使用                  | `package_share_opened`                          |

**MVP 验证门槛**（立项书 §8.3 对齐）：新用户无教学完成核心任务；任务完成率 > 60%；导出后真实发布率 > 40%；30 日复用率 > 30%。

## 9. 技术架构提示（给研发的边界条件，非详细设计）

- **形态**：Web 优先（响应式），MVP 不做小程序/App
- **前后端分离**：前端 SPA；后端 API + 任务编排引擎（步骤为状态机，支持中断/恢复/重试）
- **异步任务**：生成步骤全部异步（队列 + 轮询/SSE 推送），每个 Artifact 落对象存储
- **模型接入**：Capability 抽象层，LLM/文生图至少各接 2 家供应商，按预设可配路由与降级
- **数据模型**：任务/Run/Artifact/Confirmation 分表；产物不可变、版本化（append-only）
- **合规**：生成物标"AI 生成"元数据；用户素材权属声明（注册时确认）；操作日志留存

## 11. 开放问题（需要产品/创始人决策）

1. 素材图的肖像权/版权责任边界：用户上传竞品图或网图，平台检查到什么程度？
2. 免费层用量：几次任务/多少素材空间能在"体验完整闭环"与"防薅"间平衡？
3. 表单里商品信息是否支持淘宝/1688 链接自动解析抓取（体验大幅提升但有合规灰区）？
4. 小红书预览的样式还原度做到什么程度（像素级还原 vs 结构示意）？
5. MVP 是否收钱：付费试点（哪怕 ¥99）是立项书"付费意愿假设"最直接的验证，建议 Alpha 后即开。
